# Grygy — digitální hřiště

Ukázkový osobní web Adama Grygara. Statický HTML/CSS/JavaScript pro GitHub Pages, bez externích knihoven, analytiky nebo serveru.

## Funkce
- Generativní canvas reagující na kurzor a změny rozměrů.
- Přepínání tmavého/světlého vzhledu; preference v localStorage.
- Palety barev s kopírováním hex kódů.
- Test postřehu s osobním rekordem uloženým v tomto prohlížeči.
- Živý editor typografie a filtrování experimentů.
- Časovač odvozený od skutečného času, s pauzou a resetem.
- Příkazová paleta přes Ctrl/Cmd+K, přístupnost a reduced-motion.

## Spuštění
Otevřete index.html nebo složku obslužte libovolným statickým serverem. Kopírování do schránky vyžaduje bezpečný kontext (HTTPS/localhost).

## GitHub Pages
Publikování z větve main, kořen /. Vlastní doménu nastavte až po potvrzení registrace grygy.com. Nikdy neukládejte API klíče do zdrojů webu.
